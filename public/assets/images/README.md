# Images

Ce dossier recevra les 27 images définitives du projet.

Convention recommandée : `inside-monte-carlo-01.webp` à `inside-monte-carlo-27.webp`.

Le contenu éditorial et les chemins d’images sont centralisés dans `src/data/content.ts` afin de remplacer les médias sans modifier les composants ni la grille.
