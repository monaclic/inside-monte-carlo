# Images

Ce dossier contient les 27 images fournies dans le dossier Bureau du projet.

Les originaux restent intacts sur le Bureau. Les copies web ont été redimensionnées à 2200 px maximum et enregistrées de `inside-monte-carlo-01.jpg` à `inside-monte-carlo-27.jpg`.

Le contenu éditorial et les chemins d’images sont centralisés dans `src/data/content.ts` afin de remplacer les médias sans modifier les composants ni la grille.
